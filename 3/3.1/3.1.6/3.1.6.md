# 3.1.6. Prototipos de Interfaz

Esta sección describe las pantallas propuestas para cada módulo,
como base para la elaboración de los mockups o wireframes en la
herramienta de diseño que utilice el equipo (Figma, Balsamiq, etc.).
Cada pantalla se vincula con los requisitos funcionales (RF) que
soporta.

## Módulo 1 — Gestión de Centros (Tenants) y Planes (CHUPA)

| Pantalla                          | Elementos principales                                                                | RF relacionados        |
| --------------------------------- | ------------------------------------------------------------------------------------ | ---------------------- |
| Listado de centros                | Tabla con nombre del centro, tipo (clínica, spa, etc.), plan, estado, fecha de alta. | RF-006                 |
| Registro de nuevo centro          | Formulario: datos del centro, plan inicial, datos del administrador y primera sede.  | RF-001, RF-004, RF-008 |
| Detalle / edición de centro       | Datos generales, botón activar/suspender, historial de cambios de plan.              | RF-002, RF-003         |
| Configuración de planes y límites | Formulario con límites de usuarios, profesionales, sedes y citas mensuales por plan. | RF-004, RF-005         |
| Panel de métricas generales       | Indicadores de centros activos, citas totales, uso por plan (gráficos simples).      | RF-007                 |

## Módulo 2 — Sedes, Profesionales, Cabinas/Equipos y Disponibilidad (GOMEZ)

| Pantalla                          | Elementos principales                                                                             | RF relacionados        |
| --------------------------------- | ------------------------------------------------------------------------------------------------- | ---------------------- |
| Listado de sedes                  | Tabla de sedes del centro, dirección, cantidad de profesionales/cabinas/equipos.                  | RF-009, RF-010         |
| Registro / edición de sede        | Formulario: nombre, dirección, horario general de atención.                                       | RF-009, RF-010         |
| Listado de profesionales          | Tabla de profesionales por sede, especialidad, servicios habilitados.                             | RF-011, RF-014, RF-017 |
| Registro / edición de profesional | Formulario: nombre, especialidad, sede, servicios que realiza.                                    | RF-011, RF-014, RF-017 |
| Listado de cabinas y equipos      | Tabla de cabinas/boxes y equipos por sede, estado, acciones editar/eliminar.                      | RF-012, RF-013, RF-014 |
| Configuración de horarios         | Calendario/grilla semanal para definir disponibilidad de profesional, cabina o equipo.            | RF-015, RF-016         |
| Vista de disponibilidad conjunta  | Calendario mostrando bloques libres/ocupados cruzando profesional + cabina + equipo por servicio. | RF-018, RF-019         |

## Módulo 3 — Gestión de Citas y Concurrencia (RAMIREZ)

| Pantalla                        | Elementos principales                                                                          | RF relacionados                |
| ------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------ |
| Búsqueda de disponibilidad      | Selector de sede/servicio, calendario, franjas disponibles (profesional+cabina+equipo).        | RF-020                         |
| Formulario de nueva cita        | Datos del paciente, servicio, profesional, fecha y hora, uso de sesión de paquete (si aplica). | RF-021, RF-022, RF-028         |
| Mensaje de conflicto de horario | Aviso de que el horario ya no está disponible y sugerencia de horarios alternativos.           | RF-023                         |
| Detalle de cita                 | Estado, datos del profesional/cabina/equipo y paciente, opciones cancelar/reprogramar/no-show. | RF-024, RF-025, RF-026, RF-027 |
| Listado / historial de citas    | Tabla filtrable por estado, fecha, profesional o paciente.                                     | RF-029                         |

## Módulo 4 — Usuarios, Autenticación, Ficha Clínica, Notificaciones y Auditoría (CHAVEZ)

| Pantalla                          | Elementos principales                                                                              | RF relacionados        |
| --------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------- |
| Pantalla de inicio de sesión      | Formulario de usuario/contraseña, opción de login con proveedor externo.                           | RF-031                 |
| Listado de usuarios               | Tabla de usuarios del centro, rol asignado, estado, acciones.                                      | RF-030, RF-032         |
| Registro / edición de usuario     | Formulario: nombre, correo, rol, sede asignada (si aplica).                                        | RF-030, RF-032         |
| Configuración de roles y permisos | Matriz de permisos por rol, incluyendo acceso a información clínica.                               | RF-032, RF-033         |
| Ficha clínica del paciente        | Antecedentes, alergias, contraindicaciones, historial de procedimientos, consentimientos firmados. | RF-034, RF-035, RF-036 |
| Alerta de contraindicación        | Modal/aviso al agendar o iniciar una cita si existe una contraindicación registrada.               | RF-036                 |
| Gestión de paquetes de sesiones   | Tabla de paquetes contratados por paciente, sesiones usadas/pendientes.                            | RF-037                 |
| Historial de auditoría            | Tabla filtrable por usuario, fecha, tipo de operación y resultado.                                 | RF-040, RF-041         |
| Configuración de notificaciones   | Plantillas de mensaje/correo/SMS para confirmación, recordatorio y cancelación de citas.           | RF-038, RF-039         |

## Próximos pasos

- Elaborar los wireframes de baja fidelidad de cada pantalla en la
  herramienta que defina el equipo (Figma, Balsamiq, Draw.io, etc.).
- Validar el flujo crítico: **"Búsqueda de disponibilidad → Validación
  de ficha clínica/consentimiento → Nueva cita → Confirmación /
  Conflicto"**, dado que combina las reglas RN-005, RN-006 y RN-013.
- Prestar especial atención al diseño de la pantalla de ficha clínica
  (información sensible), asegurando que solo sea visible para los
  roles autorizados.
- Una vez definidos los mockups, enlazar aquí las imágenes o el enlace
  al archivo de diseño correspondiente.
